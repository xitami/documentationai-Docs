## Brainz im Überblick

Brainz ist ein PostgreSQL-first, mandantenfähiges SaaS-Backend für persönliches Wissensmanagement. Es verbindet einen extrem flexiblen Datenspeicher mit GraphQL, einem eingebauten Content-System und nativer KI-Integration in einer Architektur, die sich selbst hosten lässt, quelloffen ist und nicht an einen einzelnen LLM-Anbieter gebunden bleibt.

Wenn Sie Brainz einsetzen, arbeiten Sie nicht mit einer Sammlung lose gekoppelter Einzellösungen. Sie bekommen eine Plattform, die strukturierte Inhalte, semantische Suche, Echtzeit-Synchronisation, Hintergrundprozesse und KI-Workflows auf derselben Datenbasis zusammenführt. Das macht Brainz besonders interessant für Entwickler und Self-Hoster, die volle Kontrolle über Datenmodell, Infrastruktur und Integrationen behalten möchten.

<Callout kind="info">

Brainz ist vergleichbar mit einem flexiblen Backend-as-a-Service auf PostgreSQL-Basis, setzt aber auf GraphQL statt REST, bringt ein universelles Content-System mit und erweitert die Plattform um einen nativen MCP-Server für KI-Clients.

</Callout>

## Architektur-Überblick

Brainz trennt Client, API, Persistenz, Hintergrundverarbeitung und externe KI-Dienste klar voneinander. Gleichzeitig bleibt der Kern überschaubar: PostgreSQL ist das System of Record, während API, Jobs, Storage und KI-Provider gezielt darum herum aufgebaut sind.

```text
Clients
├─ Web SPA
├─ Mobile PWA
├─ iOS App
├─ Chrome Extension
└─ MCP Clients

API Layer
├─ Express
├─ PostGraphile
└─ WebSocket

Daten- und Service-Layer
├─ PostgreSQL 16
│  ├─ RLS
│  ├─ pgvector
│  ├─ pgcrypto
│  └─ tsvector
├─ BullMQ / Redis
│  └─ Background Jobs
├─ S3 Storage
│  └─ MinIO / R2
└─ AI Providers
   ├─ OpenAI
   ├─ Anthropic
   └─ Ollama
```

Diese Aufteilung hilft beim Self-Hosting, weil jede Schicht unabhängig skaliert und ersetzt werden kann. Wenn Sie lokale Modelle bevorzugen, binden Sie Ollama an. Wenn Sie objektbasierten Storage bereits betreiben, verwenden Sie einen S3-kompatiblen Dienst wie MinIO oder R2.

## Tech-Stack

Die Plattform basiert auf einem bewusst pragmatischen Stack, der sich gut in bestehende Docker- und PostgreSQL-Umgebungen integrieren lässt.

- **Node.js 20+ / Express** für API, Middleware und serverseitige Integrationen
- **PostgreSQL 16** mit `pgvector`, `pgcrypto` und Row Level Security
- **PostGraphile** für die automatische GraphQL-Schicht über dem Datenmodell
- **Better Auth** für JWT, OAuth und Zwei-Faktor-Authentifizierung
- **BullMQ + Redis** für Warteschlangen, Worker und Hintergrundverarbeitung
- **Yjs** für CRDT-basierte Echtzeit-Kollaboration
- **S3-kompatibler Storage** für Dateien, Medien und Anhänge
- **Docker / Docker Compose** für lokale Entwicklung und Deployment
